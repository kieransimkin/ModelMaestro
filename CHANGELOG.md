# Changelog

## 0.1.0 — ModelMaestro naming update (2 October 2026)

- Renamed the application, source folder and npm package to ModelMaestro / `modelmaestro`.
- Updated browser metadata, login/loading screens, navigation wordmark, initial mark and DanceFlow subtitle.
- Renamed the main React component and client hook to `ModelMaestro` and `useModelMaestro`.
- Updated backend service identity, launcher readiness check, startup messages and CI workflow name.
- Renamed the sample user service to `modelmaestro.service` and updated its paths and commands.
- Added `MODELMAESTRO_TOKEN` / `MODELMAESTRO_URL` to the standalone Socket.IO example, retaining legacy fallbacks.
- Kept existing settings, database formats, authentication protocol, engine names, pins and runtime behavior unchanged.

This source-only rebrand retains version 0.1.0; it does not claim a registry publication or newly qualified model support.
